# ターンフロー

**このゲームに実時間は存在しない。すべてターン制。**
往路・復路とも **1部屋 = 1ターン**。テキストの読了時間はゲーム状態に一切影響しない。

---

## 0. 状態オブジェクト

```js
const state = {
  // 進行
  phase: 'MOUNTAIN',      // MOUNTAIN | OUTBOUND | REVEAL | RETURN | ENDING
  room: 0,                // 現在の部屋番号

  // ゲージ
  H: 10,                  // 主人公の空腹 (0-12)
  P: 8,                   // 相方の限界 (0-12)。主人公より弱っている
  D: 3,                   // 山猫との距離（復路のみ使用）

  // 所持
  // 小物。紳士たちは penknife / pocket_watch / glasses / matches を最初から持つ。
  // dog_whistle だけは山道で犬から手に入れる
  items: ['penknife', 'pocket_watch', 'glasses', 'matches'],
  hasGun: true,           // 鉄砲（重量2・立ち絵に出る）
  hasCoat: true,          // 外套と靴（重量1・立ち絵に出る）

  // 服従（部屋番号ごとのフラグ）
  obeyed: { 2:false, 3:false, 4:false, 5:false },

  // 相方
  partnerBroken: false,   // P==0 で true。以降回復不可
  partnerPresent: true,   // 突き飛ばす／置いていくと false

  // 犬
  dogBuried: false,

  // 分岐結果
  saltApplied: false,
  caught: false,
  pushedPartner: false,
  abandonedPartner: false,
  chargedIn: false,
};
```

### 派生値

```js
const W = (state.hasGun ? 2 : 0) + (state.hasCoat ? 1 : 0);   // 重量 0-3
const clothingStage =                                          // 立ち絵の服装段階 0-3
  state.obeyed[5] ? 3 : state.obeyed[4] ? 2 : state.obeyed[2] ? 1 : 0;
const canRun = state.H > 0;
```

> **重量 W は独立ゲージではなく、常に所持状態から再計算する。** 小物は重量に影響しない。

## 1. 山道フェーズ（`MOUNTAIN`）

```
[1] カット1: 山道
    → 相方の台詞（猟師とはぐれた／腹が減った／戻ろうか）
    → 「進む」のみ

[2] カット2: 犬が倒れる
    → 演出: 犬2匹がめまいを起こして倒れる。首の銀の犬笛が光る
    → ★決断1: 3択
       ├ 犬を埋めて弔う      → H -= 2 / items.add('dog_whistle') / dogBuried = true
       ├ 笛だけ取って進む    → items.add('dog_whistle')
       └ 何もせず進む        → （笛を入手しない）
    → 相方の反応台詞（選択ごとに変える）

[3] カット3: 山猫軒の発見
    → 看板「どなたもどうかお入りください。決してご遠慮はありません」
    → 「入る」のみ
    → phase = 'OUTBOUND', room = 1
```

## 2. 往路フェーズ（`OUTBOUND`）

### 2.1 1室目（玄関）— チュートリアル専用。判断なし

```
[1] 入室演出（引き絵・フェードイン）
[2] 看板を提示
[3] 自由フェーズ（コストなし・回数無制限）
      ├ 看板を調べる  → ★必須。無害な発見をさせる（「営業中」の札など）
      └ 相方に話す
[4] 「奥へ進む」で room = 2
```

> **`調べる` を一度も使わずに1室目を出られないようにする。** 6室目で「鍵穴を覗く」を思いつけるかは、ここで決まる。

### 2.2 判断室（2〜5室）— 1ターンの処理順序

```
[1] 入室演出
      引き絵。カメラは部屋全体を見せる位置に固定

[2] 看板を提示
      Canvas 2D → テクスチャ → 板ポリ（3D空間に実在させる）

[3] 自由フェーズ（コストなし・回数無制限）
      ├ 看板を調べる      → 追加の記述（推理の手がかり）
      ├ 部屋の物を調べる  → 手がかり／伏線
      └ 相方に話す        → P の段階に応じた台詞（§11.1 参照）

[4] ★判断フェーズ ─ カメラが寄る（決断の合図）
      ├ 全部従う    → obeyed[room] = true / 要求された小物をすべて失う / reward = 4
      ├ 一部を隠す  → obeyed[room] = true / [4a]へ / reward = 2
      └ 拒否する    → obeyed[room] = false / 何も失わない / reward = 0

   [4a] 小物選択サブフェーズ（「一部を隠す」のみ）
        要求された小物のリストを提示し、隠すものを選ぶ
        隠さなかったものは失う

[5] 所持状態の更新
      3室で従った場合 → hasGun = false
      4室で従った場合 → hasCoat = false
      → W を再計算 → 立ち絵の服装段階を更新

[6] 消費処理
      H -= (1 + W)
      P -= 2          // P_DRAIN。初期8なので、譲らなければ5室目で0になる
      ※ 下限0でクランプ

[7] 報酬処理（reward > 0 のみ）
      ★決断: 報酬の配分
        ├ 自分が受け取る  → H += reward
        └ 相方に譲る      → P += reward   （partnerBroken なら選択不可）
      ※ 上限12でクランプ

[8] 限界判定
      P == 0 かつ !partnerBroken
        → partnerBroken = true
        → ★演出: 「怪しいのは……分かってる。分かってるんだ。でも、もう歩けない」
        → 以降、相方は疑問を口にしない／指示に自動で従う
      H == 0
        → 画面周縁が暗くなる／視界が揺れる（復路で各室 D -1）

[9] 相方の台詞（P の段階に応じて / partnerBroken なら沈黙）

[10] 次の部屋へ
      room < 5  → room += 1
      room == 5 → phase = 'REVEAL', room = 6
```

> **[6] の消費は「従ったかどうか」に関係なく必ず発生する。** 拒否した者は報酬を得られず、重量ぶんの追加消費だけを払う。これが「拒否には代償がある」の実装である。

### 2.3 服従フラグと立ち絵の対応

| 服装段階 | 条件 | 見た目 |
|---|---|---|
| 0 | 初期 | 正装（帽子・外套・靴） |
| 1 | `obeyed[2]` | 帽子を取り、靴の泥を落とした |
| 2 | `obeyed[4]` | 下着姿（外套・靴・金物を置いた） |
| 3 | `obeyed[5]` | クリームと香水を塗り、つやつや光っている |

**鉄砲は独立レイヤー**（`hasGun`）。3室目を拒否すれば、**下着姿で鉄砲を抱えた紳士**という状態が発生する。これは仕様であり、バグではない。

## 3. 反転フェーズ（`REVEAL` / 6室目・厨房前）

```
[1] 入室演出
      厨房前。奥に閉じた扉。手前に壺

[2] 看板を提示
      「いろいろ注文が多くてうるさかったでしょう。お気の毒でした。
       もうこれだけです。どうか体中に、壺の中の塩をたくさんよくもみこんでください」

[3] 相方の状態による分岐
      !partnerBroken → 「なあ……この扉、なんか変だ。誰か、いるんじゃないか」
                        → 「鍵穴を覗く」を強調表示
      partnerBroken  → 沈黙。強調表示なし（選択肢自体は存在する）

[4] ★選択（3択・常に全て表示される）
      ├ 壺の塩をもみこむ  → saltApplied = true → phase = 'ENDING'（COOKED）
      ├ 壺を調べる        → 「粗い塩。菜っ葉の匂いがする」→ [4]へ戻る
      └ 鍵穴を覗く        → [5]へ

[5] ★反転演出（原作準拠）
      覗こうと顔を寄せた瞬間、向こうから二つの青い眼玉が覗いている
      → 扉の向こうの会話が聞こえる（テキスト表示）
        「だめだよ。もう気がついたよ。塩をもみこまないようだよ」
      → phase = 'RETURN', D = 3 + (dogBuried ? 1 : 0), room = 6
```

> **カットシーンで真相を教えてはならない。** プレイヤーが「鍵穴を覗く」を選んだ結果として反転が起きる。誰も叫ばない。

## 4. 復路フェーズ（`RETURN`）— 1ターンの処理順序

部屋の巡回順: **6 → 5 → 4 → 3 → 2 → 1**

```
[1] 入室演出
      同じ3Dシーンを再利用。ライティングを冷色＋赤みに変更
      往路で差し出したものが、床に置かれている

[2] 障害の提示（部屋ごとに固定 / §4.1 参照）

[3] ★対処の選択
      アイテムを使う / 迂回する / 強行する
      → 消費ターン数が決まる（1 または 2）

[4] 拾得の誘惑（4室・3室のみ）
      ★決断: 拾う / 置いていく
        外套と靴 → H += 3, hasCoat = true (W +1), turnExtra +1
                   ※ 飢えているなら正解、満たされているなら距離を失うだけ
        鉄砲     → hasGun = true (W +2)。使用可能だが効果なし

[5] 相方の処理（partnerBroken のみ・復路で1回だけ）
      ★決断: 支える / 置いていく
        ※発生は厨房前（6室・復路の最初の部屋）に固定。部屋は選べない。
          復路では P が減らないので、折れているかは復路に入る時点で確定している。
        ├ 支える      → D -= 2（復路全体で1回のみ適用）
        └ 置いていく  → abandonedPartner = true, partnerPresent = false
                        → phase = 'ENDING'（ALONE）

[6] 精算（順序が重要）
      D -= turnExtra                   // 2ターン使ったら -1
      D -= penalty                     // 匂い・足跡など
      if (room !== 1) H -= (1 + floor(W/2))   // 復路でも腹が減る。玄関は消費しない
      if (!canRun) D -= 1              // H == 0 なら走れない

[7] 捕捉判定
      if (D <= 0) → [8]へ
      else        → [9]へ

[8] ★追いつかれた場合
      演出: 背後の影が部屋に伸びる
      ★決断: 突き飛ばす / 突き飛ばさない
        ├ 突き飛ばす      → pushedPartner = true → ENDING（ALONE）
        └ 突き飛ばさない  → caught = true       → ENDING（TOGETHER）

[9] 次の部屋へ
      room > 1  → room -= 1
      room == 1 → [10]へ

[10] 玄関到達（原作の再現）
      扉が開かない → 二人は泣く
      → 白熊のような犬が2匹、扉を突き破って飛び込んでくる
      → 鍵穴の眼玉が消える
      → 犬は次の扉に飛びつき、吸い込まれるように飛んで行く

      ★最後の決断
        canCharge = items.has('dog_whistle') && partnerPresent && H > 0
        ├ 逃げる                          → ENDING（ORIGINAL）
        └ 犬に続いて踏み込む（canCharge）  → chargedIn = true → ENDING（TRUE）
      ※ canCharge が false の場合、「踏み込む」は表示しない
```

### 4.1 復路の障害一覧

| 復路 | 部屋 | 障害 | 解法 | 未解決時 |
|---|---|---|---|---|
| 1st | 厨房前 | 扉が閉じている | ペンナイフ／懐中時計の鎖（1ターン） | 体当たり 2ターン |
| 2nd | 香油室 | 香水の匂いで位置がバレる（`obeyed[5]` のときのみ） | マッチで焼く（1ターン） | `D -1` |
| 3rd | 衣裳室 | 障害なし（**誘惑**） | — | — |
| 4th | 銃器室 | 障害なし（**罠**） | — | 鉄砲を撃つと `D -1` |
| 5th | 廊下 | 泥の足跡（`obeyed[2]` のときのみ） | 眼鏡で抜け道を発見（1ターン） | `D -1` |
| 6th | 玄関 | 扉が開かない | **解法なし。犬が来る** | — |

> **2nd と 5th の障害は「往路で従った結果」として発生する。** 従わなかった者にはその障害がない（代わりに重い）。往路と復路が同じ天秤を逆向きに問う構造の中核。

## 6. ターン処理の不変条件（テストで検証する）

1. `W` は常に `(hasGun?2:0) + (hasCoat?1:0)` と一致する
2. `H` と `P` は常に `0 <= x <= 12`
3. `partnerBroken` が true になったあと、`P` は増加しない
4. 往路の判断室では、必ず1回だけ消費処理が走る
5. 5種のエンディングすべてに、到達可能な入力列が存在する
6. どの選択列を辿っても、必ずいずれかのエンディングに到達する（無限ループしない）
7. 山道で「何もせず進む」を選んだ場合、`TRUE` には到達できない
8. `partnerBroken` かつ `TRUE` 到達は可能である（支えて連れて行けばよい）
