# 場面一覧（テスト・不具合報告用）

不具合を報告するときは **`S12`** のような番号か **`[O3b]`** のようなコードで指定してください。
番号は画面右上に常に出ています（クリックすると調整用の詳細が開きます）。

定義は `src/systems/scenes.js`。**並び順は物語順に固定**しており、
番号は配列の位置から決まるため、途中に挿入すると以降がずれます。

到達しうる場面がすべて登録されていることは `test/reachability.test.mjs` が検証しています
（総当たり探索で未登録の場面が1つでもあれば失敗します）。
