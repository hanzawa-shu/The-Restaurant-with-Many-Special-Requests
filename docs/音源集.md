# 音源集

**このファイルは生成物。手で編集しない。**
出典は `src/data/audio.js`。変更したら `npm run gen:docs` で作り直す。

## 方針

1. **曲は増やさず、使い回して意味を変える。**
   同じサロンワルツが、往路では「上等な料理店の音楽」に、
   調理の結末では「客のために鳴り続けている音楽」に聞こえる。
   曲を足すより、同じ曲が別の意味になるほうが効く。
2. **効果音は「その音がないと何が起きたか分からない」ものだけ。**
   足すほど画面は賑やかになるが、そのぶん静けさが減る。
   本作は止まった絵と文章で見せているので、静けさは資産である。
3. **鳴らす判断は `src/data/audio.js` の純粋関数に置く。**
   どの場面で何が鳴るかはテストで検証する。

## 効果音

**この7つだけ。** 1周あたりの回数を添えてある。
1〜2回しか鳴らないものは、その1回が物語の要になっているものだけ残した。

| id | 音 | 長さ | 回数／周 | 役目 |
|---|---|---|---|---|
| `select` | 決定 | 0.2s | 約40回／周。すべての選択肢とチップ | 選択肢を押したとき。いちばん多く鳴るので、いちばん小さく短くする |
| `door` | 扉 | 1s | 約13回／周。往路6室・復路6室・店に入る | 部屋を移るとき（暗転に重ねる）。本作の拍を刻む音 |
| `metal` | 金物 | 0.6s | 約6回／周。鉄砲を置く・拾う、金物を預ける、小物を隠す | 金属を手放す／拾うとき。奪われていく感覚を音で持たせる |
| `cloth` | 衣ずれ | 0.9s | 約3回／周。鍵穴に顔を寄せる、衣服を脱ぐ | 身体が動くとき。かぎ穴に顔を寄せる場面の「間」をここで作る |
| `eyes` | 眼玉 | 1.8s | 1回／周。★最重要 | ★かぎ穴の向こうに眼玉が現れる瞬間。この1音のために他を静かにしてある。絵の溶け込み（1.9秒）に合わせる |
| `steps` | 背後の足音 | 2s | 約4回／周。追いつかれた場面、復路の障害 | 追ってくるものの気配。ループさせて距離が詰まる場面に敷く |
| `crash` | 犬が飛び込む | 1.4s | 1回／周。復路の終点 | 玄関の扉を犬が突き破る。物語で唯一「こちら側」から来る音 |
