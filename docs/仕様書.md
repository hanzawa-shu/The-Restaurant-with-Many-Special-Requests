# 『注文の多い料理店』ゲーム 仕様書

原作: 宮沢賢治「注文の多い料理店」(1924年 / パブリックドメイン)
版: 0.1（初版）

## 0. この企画の前提

| 項目 | 決定 |
|---|---|
| 成果物 | プレイアブルなブラウザデモ（Demo_1〜7 と同格） |
| 体制 | ソロ開発。絵は後からAI生成でハメ込む |
| **成果指標** | **「面白さ」一本。「原作を読ませる」は指標から外す** |
| 原作との関係 | 舞台設定（山猫軒）と法則（命令のパラドクス）のみ借用。構成は自由に再設計 |
| プレイ時間 | 初回 約12分 / 2周目以降 約7〜8分 |
| 往路の決断 | **5〜9回**（山道1 ＋ 判断室4 ＋ 報酬配分0〜4） |
| 反転以降の決断 | **3〜9回**（下表。道によって変わる） |

> **★「9回」は往路の上限であって、遊べば必ず9回になる訳ではない。**
> 報酬配分は「従った部屋」にしか出ないので、全部拒否すると往路は5回になる。
> さらに、報酬を全部自分で取ると4室目までに相方が折れ、
> 「相方に譲る」が選べなくなるので8回に減る（一度でも譲れば9回）。
> 数字は `test/decisions.test.mjs` が実装から測って固定している。

**反転以降の決断（すべて道によって出る／出ない）**

| 場面 | 回数 | 出る条件 |
|---|---|---|
| 反転（塩／壺／鍵穴） | 1 | 固定 |
| 復路の障害 | 0〜3 | 厨房前は必ず。廊下と香油室は**従った場合だけ**発生する |
| 拾得の誘惑（鉄砲・外套） | 0〜2 | その部屋で**渡していた場合だけ** |
| 撃つか | 0〜1 | 鉄砲を拾った場合 |
| 折れた相方を支えるか | 0〜1 | 相方が折れている場合。**厨房前で1回だけ**（§8.1） |
| 追いつかれた | 0〜1 | D≤0 になった場合 |
| 最後に踏み込むか | 0〜1 | 玄関まで逃げ切った場合 |

追いつかれた場面と玄関の場面は排他（追いつかれるとそこで終わる）ので、上限は9回。

実測（`test/decisions.test.mjs`）:

| ルート | 往路 | 反転以降 |
|---|---|---|
| 全拒否 → 塩をもみこむ（調理） | 5 | 1 |
| 全拒否 → 覗く → 支える → 手を離さない（共倒れ） | 5 | 4 |
| TrueEnd 想定ルート | 8 | 6 |

### 0.1 この作品が成立する条件（設計の憲法）

以下は個別仕様より上位にある。矛盾する仕様が出たら、こちらを優先する。

1. **プレイヤーは戦えない。** 武力・戦術で山猫を倒す手段は一切存在しない。プレイヤーの唯一の力は「呼ぶこと」。
2. **プレイヤーから操作を奪わない。** 服従はすべてプレイヤー自身の選択。飢えに屈するのは相方だけ。
3. **店は脅さない。** 拒否しても通す。強制ではなく報酬で誘う。
4. **数値を画面に出さない。** 状態は演出・台詞・立ち絵で伝える。
5. **気づきはプレイヤーの手柄にする。** カットシーンで真相を教えない。
6. **見落としで詰ませない。** 失うのは常に「意図的な選択」の結果だけ。
7. **実時間を使わない。** すべてターン制。テキストはいくら読んでもよい。
8. **設計を音に依存させない。** 音の実装はゼロ。すべて視覚で成立させる。

## 1. 登場人物

### 1.1 主人公（プレイヤー）
- **無言。** 一切喋らない。意思表示は選択のみ
- 空腹ゲージ **H** を持つ
- 現代語の世界観（原作の文体は使わない）

### 1.2 相方
- **少し賢い青年風の口調。現代語。** 疑う思考を持つ
- 限界ゲージ **P** を持つ。0になると「折れる」
- **折れる = 心変わりではなく屈服。** 最後まで疑っている。ただし体が持たない
- 役割: **疑問の提示のみ。** 正解は絶対に言わない

> 原作の二人はどちらも愚かで区別がつかない。本作は**原作の二人を分解し、「疑う機能」を相方に集約した**。これは原作からの意図的な逸脱である。

### 1.3 猟犬（2匹）
- 山道で倒れて死ぬ（原作準拠）
- 首に**銀の犬笛**が付いている
- 終盤、扉を突き破って現れる（原作準拠）
- **山猫を倒すのは犬である。プレイヤーではない**

### 1.4 猟師
- 案内役。山道の時点で既にはぐれている（相方の台詞で示すのみ）
- エンディング4・5に**声とシルエットのみ**で登場（原作準拠）

### 1.5 山猫
- 姿を直接見せない。**鍵穴の眼玉、扉越しの会話、影**のみ
- 「親方」と複数の下働きがいる（原作準拠）

## 2. 全体構造

```
山道（3カット） → 往路6室 → 反転（6室目） → 復路6室 → エンディング5種
```

- **一方通行。** 往路・復路とも前の部屋に戻れない
- **途中セーブなし。** 中断したら最初から（一方通行の緊張を守るため）

## 3. 山道パート

### カット1: 山道
相方の台詞で状況を示す。「案内の猟師とはぐれた」「腹が減った」「もう戻ろうか」。

### カット2: 犬が倒れる
白熊のような犬2匹が、めまいを起こして泡を吐いて倒れる。**首に銀の犬笛が見える。**

**選択（1回目の決断）**

| 選択 | 効果 |
|---|---|
| 犬を埋めて弔う | `H -2`／**犬笛を入手**／`dog_buried = true`／**復路の初期距離 `D` が +1**（犬が近くにいる） |
| 笛だけ取って進む | **犬笛を入手**／`dog_buried = false` |
| 何もせず進む | 犬笛を入手しない（＝TrueEnd不可） |

> 原作の紳士は犬の死を「一疋二千四百円の損害」として惜しむ。主人公は無言なので、この冷たさは**台詞ではなくプレイヤーの選択**として提示する。3択のうち2つで笛は入手できるので、**見落としでは失わない**（憲法6）。
>
> **弔いには見返りを付ける。** 体力を払うのに何も返らない設計だと、「情を選ぶと純粋に不利」になり、質問7-2で決めた「情を捨てなかった者が勝つ」という思想と逆になる。弔った者は復路の初期距離が 1 増える。

### カット3: 山猫軒の発見
西洋造りの一軒家。看板「**どなたもどうかお入りください。決してご遠慮はありません**」（原作準拠）。

## 4. 往路6室

| # | 部屋 | 看板の指示 | 判断 | 役割 |
|---|---|---|---|---|
| 1 | 玄関 | 当店は注文の多い料理店です／ご承知ください | なし | **「調べる」を教えるチュートリアル** |
| 2 | 廊下 | 髪をきちんとして、靴の泥を落としてください | ★軽 | **無害に見える。「従う」を学習させる** |
| 3 | 銃器室 | 鉄砲と弾丸をここへ置いてください | ★★ | 最初の本当の決断 |
| 4 | 衣裳室 | 帽子と外套と靴、金物類をお取りください | ★★ | **相方が折れる候補地点** |
| 5 | 香油室 | 壺のクリームを塗り、香水を振りかけてください | ★★★ | もう料理の話ではない。**ここで相方が折れる** |
| 6 | 厨房前 | 体中に塩をたくさんもみこんでください | **反転** | 判断ではなく折り返し点 |

### 4.1 1室目（玄関）のチュートリアル
**「調べる」というコマンドの存在を、ここで必ず一度使わせる。** 看板を調べると、隅に小さく「営業中」の札がある等、無害な発見をさせる。

> これは6室目で「鍵穴を覗く」を思いつけるようにするための布石。憲法6を守るための必須要素であり、削ってはならない。

### 4.2 判断室（2〜5室）の3択

| 選択 | 服従フラグ | 報酬 | 小物 |
|---|---|---|---|
| **全部従う** | 立つ | **+4** | 要求された小物をすべて失う |
| **一部を隠す** | 立つ | **+2** | 隠す小物を選べる |
| **拒否する** | 立たない | **0** | 何も失わない |

**報酬は「HかPのどちらかに全額」を選ぶ。** これが4回目〜7回目の決断（報酬配分）。

> 報酬の原資は**店がよこす暖かさと前菜**であり、主人公の持ち物ではない。主人公が食料を持っていたら山猫軒に入る動機が崩壊する。ここに矛盾はない。

## 5. 小物（隠せるアイテム）

**すべて掌に握り込めるサイズ。立ち絵には出ない。** 唯一の例外は鉄砲（別レイヤーで描画）。

| 小物 | 要求される部屋 | 復路での用途 |
|---|---|---|
| **銀の犬笛** | 3・4・5（**3回**） | **TrueEnd: 犬を呼ぶ** |
| ペンナイフ | 3（とがったもの） | 厨房前の扉をこじ開ける |
| 懐中時計（鎖付き） | 4（金物類） | 鎖で扉の閂を引っ掛けて外す |
| 眼鏡 | 4（原作に明記あり） | 廊下で配膳用の抜け道を見つける |
| マッチ箱 | 4 | 香水の匂いを焼いて消す |

### 5.1 犬笛が3回要求される意味
回を追って店の口調から丁寧さが抜けていく。

- 3室: 「その他、金物類をお預かりいたします」
- 4室: 「金物は、すべてと申し上げました」
- 5室: 「まだお持ちですね。……お預かりします」

プレイヤーは「**なぜこの店は、この笛をそんなに欲しがるんだ**」と考え始める。これが推理の法則（裏＝犬）の起動装置である。

### 5.2 推理の二層構造

| 層 | 内容 | 到達難度 |
|---|---|---|
| **表**: 料理の論理 | 指示はすべて下ごしらえ。調理を妨げるものを残せばよい | 3室目あたりで見抜ける |
| **裏**: 犬 | 店が執拗に欲しがるものが答え。守り抜けば犬が来る | 最後まで気づきにくい |

表に到達した者が良い結末に届き、**裏に到達した者だけが TrueEnd に届く。**

## 6. リソースモデル

### 6.1 ゲージ

| 記号 | 名称 | 範囲 | 初期値 |
|---|---|---|---|
| **H** | 主人公の空腹 | 0〜12 | **10** |
| **P** | 相方の限界 | 0〜12 | **8** |
| **W** | 重量（派生値） | 0〜3 | 3 |

**W は独立ゲージではない。** `W = (鉄砲を持っている ? 2 : 0) + (外套と靴を持っている ? 1 : 0)`

**小物は重量に影響しない。**（掌に握れるサイズだから）

### 6.2 往路の消費（判断室 2〜5室、各室で1回）

```
H -= (1 + W)
P -= 2
（従った場合）報酬 +4 または +2 を H か P のどちらかに全額加算
```

**P は初期値 8・消耗 2 なので、報酬を一度も譲らなければ 5室目（往路の最後）で必ず折れる。**
折れれば6室目の警告が出ない。つまり——

> **言われた通りにした者は、最後の警告も失う。**

逆に、一度でも報酬を譲れば相方は持ちこたえる。ただしその分、自分が飢える。

### 6.2.1 復路の消費

**復路でも部屋ごとに腹が減る。**

```
H -= (1 + floor(W / 2))      // 玄関（1室・終点）では消費しない
P は変化しない                // 相方の限界は往路でしか動かない
```

往路の `1 + W` ほど重くはしない。復路は6室あり、そこで `1 + W` を課すとどのルートでも確実に飢え死にする。重量は半分だけ効かせる。

> **★この消費がないと復路が空回りする。** Phase 1 で実際に空回りしていた。`H` が復路で意味を持たないと、外套の「+3」に価値が生まれず、衣裳室と銃器室が天秤として成立せず、復路6室のうち3室に実質的な決断が存在しなくなる。

### 6.3 限界状態

| 状態 | 条件 | 効果 |
|---|---|---|
| **相方が折れる** | `P == 0` | 以降 P は回復不可／相方は自動で従う（服従フラグが自動で立つ）／**疑問の提示をしなくなる** |
| **主人公が走れない** | `H == 0` | 復路の各室で **+1ターン**／画面周縁が暗くなり視界が揺れる |

**H == 0 はゲームオーバーではない。** 走れなくなるだけ。憲法2を守るため、飢えで操作を奪ってはならない。

### 6.4 バランス検証

**以下の数値は `test/balance.test.mjs` が実装と一致することを検証している。**
ここがズレたら、仕様書と実装のどちらかが嘘をついている。

> **★ここに書いてある3ルートは「読んで分かるための例」であって、検証の範囲ではない。**
> 不変条件そのものは `test/reachability.test.mjs` が**総当たりで**保証している。
>
> | 何を | どう保証しているか |
> |---|---|
> | 行き止まりが無い（詰みが無い） | 到達しうる全状態で「選べる選択肢が1つ以上ある」ことを確認。**81,219 状態** |
> | 5種すべてに到達できる | 総当たり探索で到達した結末の集合が5種と一致することを確認 |
> | 無限ループしない | 状態のハッシュで訪問済みを弾き、上限を超えたら失敗させる |
>
> 探索は「一部隠す」「拾得」「支える」を含むすべての組み合わせを通る。
> COOKED も中間パターンもこの中に入っている（終端 28,868 のうち COOKED は 1,942）。
>
> `D`（追跡距離）の範囲も同じ探索から取っている（`test/decisions.test.mjs`）。
>
> - **上限 4** = 初期値3 ＋ 犬を弔った +1。これを超えるなら加算が壊れている
> - **下限 −2**。捕捉判定（`D<=0`）を少し下回るだけで、深く沈まない
> - 追いつかれる道（10,952 状態）と玄関まで逃げ切る道（2,932 状態）が**両方ある**
>
> つまり「常に `D<=0`」でも「一度も追いつかれない」でもない。減算が重なっても発散しない。

**全拒否（何も従わない）**
```
W=3 のまま。H: 10 → 6 → 2 → 0 → 0（4室目で枯渇）
P: 8 → 6 → 4 → 2 → 0（報酬ゼロなので5室目で折れる）
結果: 走れない ＋ 相方も折れている
→ 復路で各室 D-1。相方を支えれば更に D-2 → 必ず追いつかれる
```
→ 構想「何も従わないと必ず捕まる」が成立する。

**全服従（言われた通りにする / 報酬は自分が取る）**
```
2室: W=3, H 10-4=6, +4 → 10   P 8-2=6
3室: W=1, H 10-2=8, +4 → 12   P 4
4室: W=0, H 12-1=11, +4 → 12  P 2
5室: W=0, H 12-1=11, +4 → 12  P 0 → 折れる
結果: H=12 で健康。しかし小物ゼロ・香水あり・丸腰・そして相方が折れている
→ 6室目の警告が出ない。復路の障害も1つも回避できない
```

> **★ 従い続けると H は上限12に張り付く。これは意図した設計である。**
> 従う ＝ 腹は満たされるが丸腰になる／拒否 ＝ 装備は残るが飢える。
> この二律背反が本作の中核なので、全服従で H が飽和するのは正しい。

**TrueEnd 想定ルート（相方に譲り、大きいものを渡し、小物を守る）**
```
山道: 犬を埋める      H 10-2=8 / 犬笛入手 / 復路の D が +1
2室: 全部従う         W=3, H 8-4=4, +4 → 8   P 8-2=6   （泥を落とす）
3室: 一部隠す         W=1, H 8-2=6, +0 → 6   P 6-2=4, +2 → 6  ★相方に譲る
4室: 一部隠す         W=0, H 6-1=5, +2 → 7   P 6-2=4   （時計を渡す。笛・眼鏡・マッチを隠す）
5室: 拒否             W=0, H 7-1=6, +0 → 6   P 4-2=2   （クリームと香水を塗らない）
結果: H=6 / P=2 / W=0 / 香水なし / 笛・ナイフ・眼鏡・マッチ所持
→ 相方は折れていない。復路の障害はすべて手持ちの小物で解ける
```

**2室目には従うのが得である。** 泥を落とすと復路の廊下に足跡が残るが、眼鏡を隠しておけば代償なしで解ける。従って得た +4 の方が価値が高い。**「どの指示に従い、どの小物を守るか」の組合せが実際に効いている。**

**★ TrueEnd に到達するには、相方に一度は報酬を譲らなければならない。**
譲らなければ相方は5室目で折れ、6室目の警告が消え、復路では支える代償を払うことになる。
質問7-2で決めた「情を捨てなかった者が勝つ」が、数値として実装されている。

> **この数値は初期値であり、実装後の調整を前提とする。** 到達可能性は自動テストで保証できるが、「面白いかどうか」は数値では保証できない。成果指標が「面白さ一本」である以上、実際に遊んで調整する工程は省略できない。

## 7. 反転（6室目・厨房前）

看板: 「いろいろ注文が多くてうるさかったでしょう。お気の毒でした。もうこれだけです。どうか体中に、壺の中の塩をたくさんよくもみこんでください」

**選択肢は常に3つ存在する。**

| 選択 | 結果 |
|---|---|
| 壺の塩をもみこむ | → **エンディング1「調理」** |
| 壺を調べる | 塩ではない粗い塩。菜っ葉の匂い（手がかり） |
| **鍵穴を覗く** | → **覗こうとした瞬間、向こうから二つの青い眼玉が覗いている**（原作準拠）→ 復路へ |

### 7.0 原作の記述（ここは忠実に作る）

> 奥の方にはまだ一枚扉があって、**大きなかぎ穴が二つつき、銀いろのホークとナイフの形が切りだしてあって**、
> 「いや、わざわざご苦労です。／大へん結構にできました。／**さあさあおなかにおはいりください。**」
> と書いてありました。**おまけに**かぎ穴からはきょろきょろ二つの青い眼玉がこっちをのぞいています。

守るべき点。

| 項目 | 原作 | 実装 |
|---|---|---|
| 鍵穴の数 | **二つ** | 扉の絵に二つ。横並び・水平中央・中央よりやや上 |
| 鍵穴の形 | **銀いろのホークとナイフの形に切りだしてある** | 左がフォーク、右がナイフの輪郭 |
| 扉の字 | 「いや、わざわざご苦労です／大へん結構にできました／さあさあおなかにおはいりください」 | 覗いたあと、看板の板の文字がこれに変わる |
| 眼玉 | 二つ。青い。**「おまけに」** | 一枚絵を2枚（扉／眼玉）重ねて溶かす。復路の部屋では扉ごと差し替える（`kitchen_door` → `kitchen_door_eyes`） |
| 塩壺 | **立派な青い瀬戸の塩壺** | プロンプトに明記 |

> **★眼玉を別の小片として扉に重ねる実装は破棄した。**
> 扉と眼玉を別々に生成すると木目も鍵穴の位置も合わず、小片の縁が見える。
> 実際に「二つの目が嵌った装飾パネル」が生成され、暗い扉の上に明るい四角が浮いた。
> 覗いたカットは**同じ画角の2枚をクロスディゾルブ**して見せ（設計書 §11.1.2）、
> 復路の部屋では扉のテクスチャごと差し替える。

**「おまけに」の順序を崩さない。** 眼玉を先に見せると、
「扉の字を読んで、そのうえ見られていた」という二段の恐怖が消える。演出は必ずこの順で出す。

1. 奥の方に、まだ一枚扉があった
2. 大きなかぎ穴が二つつき、銀いろのホークとナイフの形が切りだしてある
3. ［扉の字］いや、わざわざご苦労です／大へん結構にできました／さあさあおなかにおはいりください
4. ——おまけに、かぎ穴からはきょろきょろと二つの青い眼玉が、こっちをのぞいていた

> **本作の逸脱**: 原作では塩の字と奥の扉の字は別の扉に書かれている。
> 本作は文字を看板の板に集約しているので、**同じ板の字が変わる**形にした。
> 「読み返したら文面が変わっている」という怖さが加わる。

### 7.1 相方の状態による差

| 相方 | 挙動 |
|---|---|
| **折れていない（P > 0）** | 「なあ……この扉、なんか変だ。誰か、いるんじゃないか」と言う。**鍵穴の選択肢が強調表示される** |
| **折れている（P == 0）** | 何も言わない。**強調表示もない**（選択肢自体は存在する） |

> 相方を支えなかったプレイヤーには、最後の警告が届かない。ただし1室目で「調べる」を教えているので、**知識があれば自力で到達できる**（憲法6）。ハードロックではなく、ヒントの有無の差である。

## 8. 復路6室（逆走）

**往路で差し出したものは、その部屋に置いてある。拾える。**

| 復路 | 部屋 | 内容 |
|---|---|---|
| 1st | 厨房前 | **閉じた扉。** ペンナイフか懐中時計の鎖で開く。どちらも無ければ2ターン（体当たり） |
| 2nd | 香油室 | 香水を塗っていると**匂いで位置がバレる**（`D -1`）。マッチがあれば焼いて回避（1ターン） |
| 3rd | 衣裳室 | **脱いだ外套と靴がある。内ポケットに前菜が残っている。** 拾えば `H +3` だが `W +1` と1ターン（**条件付きの正解**） |
| 4th | 銃器室 | **置いた鉄砲がある。** 拾えば `W +2` と1ターン。**撃てるが効かない**（さらに `D -1`）（**純粋な罠**） |
| 5th | 廊下 | 落とした泥に**足跡が残る**（`D -1`）。眼鏡があれば配膳用の抜け道で回避 |
| 6th | 玄関 | **扉が開かない。** ここで詰み、泣く → **犬が来る**（原作準拠） |

### 8.0 外套は「罠」ではなく「条件付きの正解」である

- **飢えているなら拾うのが正しい。** 走れない状態が3室続く方が、重量の1ターンより高くつく
- **満たされているなら拾うべきでない。** 距離を1失うだけで何も得ない

純粋な罠より良い。**同じ選択肢の正解が、それまでの自分の選択によって反転する。**
一方、鉄砲は拾って撃てば必ず損をする純粋な罠であり、往路で積み上げた無力感を守る（質問7-2）。

### 8.1 追跡（山猫の距離 D）

- **`D` 初期値 = 3**（犬を弔っていれば **4**）
- プレイヤーが1部屋進むと山猫も1部屋進む → `D` は変わらない
- 障害で余分にターンを使うと `D -1`
- `H == 0` の場合、各室で **`D -1`**（走れない）
- 相方が折れている場合、**支える → `D -2`（復路全体で1回）** / **置いていく → エンディング3「独り」確定**
  - **発生する場所は厨房前（6室・復路の最初の部屋）に固定。プレイヤーは部屋を選べない。**
    復路では `P` が減らない（`consumeReturn` は `H` だけ）ので、
    折れているかどうかは復路に入る時点で決まっており、途中で折れることはない。
    厨房前の障害（閉じた扉）を片付けた直後に一度だけ出る。
    `test/decisions.test.mjs` が場所と「二度出ない」ことを検証している。
- **`D <= 0` になった時点で追いつかれる** → 突き飛ばし選択

### 8.2 追いつかれたときの選択（原作にない、本作独自の場面）

| 選択 | 結果 |
|---|---|
| 相方を突き飛ばす | → **エンディング3「独り」** |
| 突き飛ばさない | → **エンディング2「共倒れ」** |

> この選択の重さは、道中どれだけ相方を支えたかで変わる。ずっと報酬を譲ってきた相手を突き飛ばすのか、最初から見捨て続けた相手をさらに突き飛ばすのか。**同じボタンの意味が、前半の行動で変わる。**

### 8.3 玄関に到達した場合（原作の再現）

二人は泣く。**そのとき白熊のような犬が2匹、扉を突き破って飛び込んでくる。** 鍵穴の眼玉が消える。犬は次の扉に飛びつき、吸い込まれるように飛んで行く。

**ここで最後の選択。**

| 選択 | 条件 | 結果 |
|---|---|---|
| **逃げる** | なし | → **エンディング4「原作」** |
| **犬に続いて踏み込む** | 犬笛所持 かつ 相方が隣にいる かつ `H > 0` | → **エンディング5「TrueEnd」** |

条件を満たさない場合、「踏み込む」は選択肢として表示されない（またはグレー表示）。

> 原作は山猫に決着をつけていない。室が煙のように消え、扉の向こうの声だけが描かれる。**ここがゲームだけが踏み込める唯一の隙間である。**

## 9. エンディング5種

| # | ID | 名称 | 条件 |
|---|---|---|---|
| 1 | `COOKED` | **調理** | 6室目で鍵穴を覗かず、塩をもみこんだ |
| 2 | `TOGETHER` | **共倒れ** | `D <= 0` になり、突き飛ばさなかった |
| 3 | `ALONE` | **独り** | `D <= 0` になり突き飛ばした／または折れた相方を置いていった |
| 4 | `ORIGINAL` | **原作** | 玄関に到達し、逃げた |
| 5 | `TRUE` | **TrueEnd** | 玄関に到達し、条件を満たして踏み込んだ |

### 9.1 判定式（擬似コード）

```js
function judgeEnding(state) {
  if (state.saltApplied)            return 'COOKED';
  if (state.caught) {
    return state.pushedPartner ? 'ALONE' : 'TOGETHER';
  }
  if (state.abandonedPartner)       return 'ALONE';
  // 玄関に到達し、犬が来た
  const canCharge =
    state.hasItem('dog_whistle') &&
    state.partnerPresent &&
    state.H > 0;
  if (canCharge && state.chargedIn) return 'TRUE';
  return 'ORIGINAL';
}
```

### 9.2 各エンディングの内容

**1. 調理**
塩をもみこむ。扉が開く。暗い。「へい、いらっしゃい」——画面が閉じる。

**2. 共倒れ**
相方を離さなかった。二人とも捕まる。扉の向こうで「にゃあお、くゎあ、ごろごろ」。

**3. 独り**
一人で山を下りる。猟師が来る。団子を出される。**食べられない。**

**4. 原作**（原文準拠）
犬が飛び込む。逃げる。室が煙のように消え、草の中に立っている。**上着や靴や財布やネクタイピンが、枝にぶらさがり、根もとに散らばっている。** 犬がふうとうなって戻ってくる。猟師が「旦那あ、旦那あ」と叫びながら来る。団子を食べ、山鳥を買って東京に帰る。

> **しかし、一ぺん紙くずのようになった二人の顔だけは、東京に帰っても、お湯にはいっても、もうもとのとおりになおりませんでした。**

そして——**どこか別の山に、また看板が立つ。**

**5. TrueEnd**
犬に続いて踏み込む。暗闇。**主人公は銀の犬笛を口にあてる。**

音は鳴らない。人間には聞こえない。**しかし犬が振り向く。**

犬が親方の山猫を倒す。店は二度と現れない。

猟師が来る。団子を食べる。犬2匹を連れて、二人で山を下りる。

**顔は戻らない。** 鉄砲も外套も店に置いてきた。

> **失ったものは戻らない。しかし、見捨てなかったものは戻ってくる。**
>
> ★**これは設計として持つだけで、作中では絶対に言わない。**
> TrueEnd の末尾はこの一文を書いていたが、主題を登場人物や語りが言い切ると
> 読み手が気づく余地が消える。いまは「犬が二人のあいだを離れずに歩いていた」で見せる。

### 9.3 なぜ TrueEnd でも顔が戻らないのか
原作で最も鋭い一行は「助かったのに、顔だけは二度と元に戻らなかった」である。ここを「TrueEndだから全部解決」にすると、**作品が持っていた一番怖い部分を、ご褒美と引き換えに捨てることになる。** 4と5の差は「山猫に決着をつけたかどうか」であり、傷の有無ではない。

## 11. 表示方針

**数値は一切表示しない。**

| 伝えたいこと | 表現 |
|---|---|
| H（空腹） | 画面周縁の暗さ、視界の揺れ、立ち絵の姿勢（5段階） |
| P（相方の限界） | **台詞の段階**と表情差分 |
| W（重量） | 立ち絵のシルエット（鉄砲・外套の有無が見えている） |
| D（追跡） | 部屋に伸びる影、扉の隙間、足音の視覚表現 |

### 11.1 相方の台詞段階

| P | 段階 | 表情 | 台詞の例 |
|---|---|---|---|
| 8以上 | 4 | 疑い | 「妙だぞ、この店。誰もいないのに看板だけある」 |
| 7〜6 | 3 | 困惑 | 「……従うのか？　まあ、ここまで来たしな」 |
| 5〜4 | 2 | 懇願 | 「腹が減った。悪いけど、少し休ませてくれ」 |
| 3〜2 | 1 | 懇願 | 「もう歩けない。頼む、なんでもいいから食わせてくれ」 |
| 1〜0 | 0 | 屈服 | 「**怪しいのは……分かってる。分かってるんだ。でも、もう歩けない**」 |

**閾値は実際に取りうる P の値に合わせている。** P は 8 から始まり判断室ごとに 2 減るので、
`8 → 6 → 4 → 2 → 0` を辿る。この5段階がちょうど1部屋ずつ対応する。

> 以前は段階4の閾値が 9 だったため、初期値 8 では段階4に一度も入らず、
> **最初の台詞が誰にも見られなかった。**

**折れた後、相方は疑問を口にしない。** 指示に自動で従う。
